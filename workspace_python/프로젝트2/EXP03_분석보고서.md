# EXP-03 — YOLOv11s 해상도 실험 분석 보고서

> 작성일: 2026-04-07  
> 프로젝트: 자동차 도장 표면 결함 탐지 (현대오토에버 Track A 데이터셋)

---

## 1. 실험 목적

EXP-02(YOLOv11s, imgsz=640)에서 확인된 **소형 결함 탐지 약점**을 이미지 해상도 향상(640→832)으로 개선할 수 있는지 검증한다.

- **독립 변인**: 입력 해상도 (imgsz 640 → 832), 배치 크기 (16 → 8)
- **통제 변인**: 모델(YOLOv11s), epochs, seed, patience, optimizer, 데이터셋 — 모두 동일
- **핵심 비교 지표**: `mAP@0.5:0.95`, 특히 gap_fault / paint_drip / dust 클래스

### 개선 대상 클래스 (EXP-02 기준)

| 클래스 | EXP-02 mAP@0.5:0.95 | 문제 원인 |
|---|---|---|
| gap_fault | 0.871 | bbox가 선형으로 길어 IoU 손실 |
| paint_drip | 0.931 | bbox 평균 면적 0.0029 — 매우 작음 |
| dust | 0.955 | bbox 작고 흐릿함 |

## 4. 학습 과정

### 4.1 에폭별 지표 추이

| Epoch | box_loss | cls_loss | dfl_loss | mAP@0.5 | mAP@0.5:0.95 |
|---|---|---|---|---|---|
| 1 | 1.194 | 3.696 | 1.057 | 0.845 | 0.614 |
| 5 | 0.982 | 0.856 | 0.999 | 0.876 | 0.672 |
| 50 | 0.683 | 0.467 | 0.879 | 0.992 | 0.866 |
| 100 | 0.541 | 0.386 | 0.833 | 0.993 | 0.901 |
| 200 | 0.463 | 0.325 | 0.821 | 0.994 | 0.929 |
| 300 | 0.362 | 0.242 | 0.786 | 0.993 | 0.940 |

- 300 epoch 풀 학습 완료 (patience 50 미도달 = 끝까지 미세 개선 지속)
- **소요 시간: 102.4분 (약 1시간 42분)**
- EXP-02(52.8분) 대비 **49.6분 (93.9%) 증가** — imgsz 증가 + batch 감소의 이중 효과

### 4.2 수렴 속도 비교

| 구간 | EXP-02 (v11s/640) | EXP-03 (v11s/832) |
|---|---|---|
| Epoch 1 | 0.535 | 0.614 |
| Epoch 5 | 0.727 | 0.672 |
| Epoch 50 | 0.930 | 0.866 |
| Epoch 100 | 0.947 | 0.901 |
| Epoch 200 | 0.950 | 0.929 |

- EXP-03은 초기 수렴은 비슷하나 **중반~후반 수렴이 EXP-02보다 느림**
- batch=8로 줄면서 gradient noise 증가 → 수렴 안정성 저하 추정

## 6. 핵심 비교: 개선 대상 클래스 분석

### 6.1 개선 대상 3개 클래스 결과

| 클래스 | EXP-02 (640) | EXP-03 (832) | 차이 | 판정 |
|---|---|---|---|---|
| **dust** | 0.955 | **0.965** | **+0.010** | ✅ 개선 |
| **paint_drip** | 0.931 | 0.926 | −0.005 | ❌ 미개선 |
| **gap_fault** | 0.871 | 0.847 | **−0.024** | ❌ 악화 |

### 6.2 분석

- **dust** (+0.010): 해상도 향상으로 작은 이물질의 특징 추출 개선 → **유일한 개선 성공 케이스**
- **paint_drip** (−0.005): bbox가 매우 작아(면적 0.0029) 해상도만으로는 개선 불충분. 샘플 수 14개로 통계적 변동 범위 내
- **gap_fault** (−0.024): 선형으로 긴 bbox 특성상 해상도 증가 효과 미미. batch=8로 줄면서 오히려 **gradient 불안정으로 성능 하락**. Recall도 0.987→0.952로 하락

## 8. 최종 판정

### 8.1 판정 기준 적용

| 결과 | 결론 |
|---|---|
| EXP-03 mAP@0.5:0.95 = 0.9530 ≤ EXP-02 0.9569 | **해상도 향상 효과 없음** |

### 8.2 종합 결론

> **최종 모델: EXP-02 (YOLOv11s, imgsz=640, batch=16)**
>
> - 전체 mAP@0.5:0.95 **0.9569**로 3개 실험 중 최고
> - 학습 시간 52.8분으로 가장 효율적
> - 추론 속도 ~5.9ms로 실시간 적용 가능
> - 해상도 증가(EXP-03)는 dust, orange_peel에서 부분 개선을 보였으나, gap_fault 악화와 전체 성능 하락으로 상쇄

### 8.3 해상도 실험 실패 원인 분석

| 원인 | 설명 |
|---|---|
| batch 크기 감소 | 16→8로 VRAM 대응했으나, gradient noise 증가로 수렴 불안정 |
| 데이터 특성 | 결함 bbox가 이미 640px에서 충분히 표현되는 크기 |
| gap_fault bbox | 선형(긴 직사각형) 형태로 해상도보다 aspect ratio 대응이 필요 |
| 학습 효율 저하 | 동일 300 epoch에서 수렴 속도가 느려 최적점 미달 |
