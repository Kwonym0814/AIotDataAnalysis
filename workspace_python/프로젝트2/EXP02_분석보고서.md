# EXP-02 — YOLOv11s 비교 실험 분석 보고서

> 작성일: 2025-07-09  
> 프로젝트: 자동차 도장 표면 결함 탐지 (현대오토에버 Track A 데이터셋)

---

## 1. 실험 목적

EXP-01(YOLOv8s) 베이스라인과 **동일 조건**에서 YOLOv11s를 학습하여, 아키텍처 변경만으로 얻을 수 있는 성능 차이를 정량 비교한다.

- **독립 변인**: 모델 아키텍처 (YOLOv8s → YOLOv11s)
- **통제 변인**: epochs, imgsz, batch, seed, patience, optimizer, 데이터셋 — 모두 동일
- **핵심 비교 지표**: `mAP@0.5:0.95`

## 3. 모델 아키텍처 비교

| 항목 | EXP-01 (YOLOv8s) | EXP-02 (YOLOv11s) |
|---|---|---|

## 7. EXP-01 vs EXP-02 비교 분석

### 7.1 전체 지표 비교

| 지표 | EXP-01 (YOLOv8s) | EXP-02 (YOLOv11s) | 차이 |
|---|---|---|---|
| mAP@0.5 | 0.9950 | 0.9950 | ±0.0000 |
| mAP@0.5:0.95 | 0.9522 | **0.9569** | **+0.0047** |
| Precision | 0.9904 | **0.9916** | +0.0012 |
| Recall | 0.9929 | **0.9984** | +0.0055 |
| 학습 시간 | 77.3분 | **52.8분** | **−24.5분** |
| Parameters | 11.1M | **9.4M** | −1.7M |
| GFLOPs | 28.7 | **21.3** | −7.4 |

### 7.2 클래스별 mAP@0.5:0.95 비교

| 클래스 | EXP-01 (v8s) | EXP-02 (v11s) | 차이 | 판정 |
|---|---|---|---|---|
| scratch | 0.988 | 0.992 | +0.004 | v11s ↑ |
| dent | 0.995 | 0.995 | ±0.000 | 동일 |
| paint_bubble | 0.981 | 0.990 | +0.009 | v11s ↑ |
| paint_drip | 0.940 | 0.931 | −0.009 | v8s ↑ |
| dust | 0.939 | 0.955 | +0.016 | **v11s ↑↑** |
| orange_peel | 0.954 | 0.952 | −0.002 | ≈동일 |
| crack | 0.957 | 0.970 | +0.013 | **v11s ↑↑** |
| gap_fault | 0.865 | 0.871 | +0.006 | v11s ↑ |

**분석:**
- 8개 클래스 중 **5개에서 YOLOv11s 우세**, 1개 동일, 2개에서 YOLOv8s 소폭 우세
- **가장 큰 개선**: dust (+0.016), crack (+0.013) — 소수 / 작은 결함 탐지에서 효과적
- **소폭 하락**: paint_drip (−0.009), orange_peel (−0.002) — 유의미한 차이 아님
- **공통 약점**: gap_fault는 양 모델 모두 최저 성능 (v11s에서도 0.871)

### 7.3 종합 판정

| 기준 | 판정 |
|---|---|
| 정확도 (mAP@0.5:0.95) | **YOLOv11s 우세** (+0.0047) |
| 학습 효율 | **YOLOv11s 우세** (31.7% 시간 단축) |
| 모델 경량성 | **YOLOv11s 우세** (파라미터 15.3% 감소) |
| 수렴 속도 | **YOLOv11s 우세** (초기 에폭에서 빠른 수렴) |

> **결론: YOLOv11s가 모든 관점에서 YOLOv8s를 상회한다.**  
> → **EXP-03은 YOLOv11s 기반으로 진행 권장**
